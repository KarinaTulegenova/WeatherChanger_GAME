# PRACTICE WORK 4
### Working with Multimedia
#### Introduction

This project presents an interactive weather animation system developed in Unity.
The main goal of the project is to demonstrate different weather conditions in a
3D environment using particle systems, lighting changes, audio effects,
environmental interaction, and user interface controls. The system allows the user
to switch between Rain, Snow, and Clear weather modes through UI buttons.

#### The project includes several core weather effects. The Rain mode uses a particle

system to simulate falling rain, while the Snow mode uses a separate particle
system to create snowfall. Both effects are configured with appropriate movement
direction, speed, and density, so they do not remain at default settings. The Clear
mode disables weather particles and returns the scene to a normal state.
